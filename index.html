MSc capstone · University of Alberta · 2026

TransitSync: offline-first fleet tracking

Buses in areas with patchy cellular coverage lose GPS, engine and ticketing data whenever they drop offline. I built an edge-to-cloud pipeline that treats outages as normal: each bus buffers every event locally and keeps seat sales in persistent storage so they survive power loss, then syncs to Azure IoT Hub with exponential backoff once the signal returns.

4event types: trips, telemetry, alerts, tickets
3operator dashboards
1public passenger portal on Azure

A Python cloud router sorts events into Azure Cosmos DB containers partitioned by vehicle. Every event records its sync delay, so operators can map cellular dead zones along a route, and passengers can look up any bus live on a Flask portal hosted on Azure App Service.

Rail Defect Detection with Deep Learning

A computer-vision system that automatically finds missing fasteners and defective fishplates on railway tracks, two faults that can lead to derailments. I collected the images myself on the Akhaura–Sylhet line of Bangladesh Railway, labelled them, and trained and compared several object-detection models.

YOLOv5 Large and Extra-Large outperformed EfficientDet-D01 and Faster R-CNN (ResNet-152) on mAP@[0.5:0.95], and held up on track photos taken from angles the model never saw in training.
